## Goal

Show you what's actually happening — where your time goes, why you procrastinate, which areas are neglected — and add the career growth tools.

**Exit criterion:** the insights dashboard and procrastination insights reflect at least four cycles of real data, and the career tools are in use.

## Scope

| Area | PRD IDs |
|---|---|
| Insights dashboard | INS-1 cycle completion trend, focus hours, completion by area, ritual consistency, XP |
| Procrastination insights | INS-2 skip reasons, most-skipped areas/goals, day-of-week patterns, postponements before completion, stale trend |
| Deeper insights | INS-3 time vs values, INS-4 mood/energy correlations |
| Career | CAR-2 skills tracker, CAR-3 learning queue, CAR-4 job search pipeline |
| Balance | AREA-3 area health, AREA-4 wheel of life |
| Workflow | HAB-5 routines, TASK-8 task dependencies |
| Capture and polish | Email-to-inbox, email fallback for the weekly report (NOT-7), app badge (PWA-6), journal search (JRN-3) |

## Known decisions and risks

- Charts library (Recharts vs Visx) — follow DESIGN.md and the dataviz guidance.
- Insights must work from data already on the device (offline) where possible.
