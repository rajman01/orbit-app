## How we use these docs

- **Before a phase:** review its plan, settle the listed decisions, and add detail (Phase 2+ docs are outlines until then).
- **During:** tick off implementation steps and add a line to the build log for each meaningful change, fix or change of plan.
- **After:** mark it complete, record what changed from the plan and any known issues, and update the status here and in PRD §21.
- **The PRD changes only when the product changes** (features, decisions, scope) — not for build progress.
